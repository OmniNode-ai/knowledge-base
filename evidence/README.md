# Evidence

Links between architectural claims and durable proof artifacts — PRs, CI runs, replay validation, benchmarks, and integration test results. Evidence files do not contain the proof themselves; they link to it and describe what it demonstrates.

Evidence files are added incrementally as claims are proven post-publication — not every accepted ADR or confirmed pivot has one yet. An ADR or pivot without a linked evidence file here is an unproven claim, not a false one; treat it as a hypothesis pending durable proof until an evidence file for it is added.
