# Pivots

Architectural pivots — first-class evolutionary artifacts capturing fundamental changes in understanding. A pivot is not a bug fix or a refinement; it is a record of a moment when the team discovered that a core assumption was wrong or incomplete, and describes both what changed and what operational pressure forced the change.

**Lifecycle:** Observed → Emerging → Accepted → Historical → Superseded

Observed means early signals exist. Emerging means the pattern is consistent but not fully confirmed. Accepted means operational evidence supports the new model. Historical means the pivot is part of the stable record. Superseded means a later pivot replaced this understanding.
